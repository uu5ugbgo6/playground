# Threat Modeling Checklist

Quick reference for reviewing system designs.

## 1. Define Scope
- [ ] Identify system boundaries and trust zones.
- [ ] List assets, data flows, and entry points.

## 2. Identify Threats
- [ ] Use STRIDE (Spoofing, Tampering, Repudiation, Information Disclosure, DoS, Elevation of Privilege).
- [ ] Consider attacker personas and motivations.

## 3. Assess Risk
- [ ] Rate likelihood and impact.
- [ ] Prioritize top risks.

## 4. Mitigations
- [ ] Define controls for each risk.
- [ ] Validate with a security review.

## 5. Document
- [ ] Record decisions and assumptions.
- [ ] Keep this doc updated as the system changes.
